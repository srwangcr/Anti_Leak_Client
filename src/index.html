🔍 Anti Leak Client

Huellas criptográficas, catálogo local, escaneo por lotes e informes forenses. Sin Google y sin API keys.

1. Analizar una imagen

Todo se calcula en tu computadora: SHA-256, pHash, dimensiones y EXIF.

2. Catálogo local

Base de datos SQLite guardada en la carpeta de configuración de la app.

3. Escaneo por lotes

Arrastrá una carpeta acá o elegila con el botón. Detecta duplicados y copias manipuladas por distancia de Hamming.

📂 Soltá una carpeta aquí para escanearla

4. Denuncia semiautomática (borrador)

Genera un informe forense y un borrador estructurado con texto listo para copiar y el paso a paso para reportar la foto. No se envía nada automáticamente.

Si ya hiciste la búsqueda web arriba, se reutiliza ese resultado y no se vuelve a subir la imagen.

5. Bóveda segura (opcional)

Guarda credenciales de integraciones futuras en el keychain del sistema operativo. Nunca se escriben en disco.
